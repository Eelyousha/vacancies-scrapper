# API и интерфейс

API возвращает JSON либо HTML-фрагменты для HTMX. Ошибки используют единый формат и корректные HTTP-коды.

| Метод и путь | Назначение |
|---|---|
| `GET /` | Dashboard |
| `GET /api/vacancies` | Фильтры `source_id`, `listing_status`, `user_status`, `run_id`, поиск, сортировка и пагинация |
| `PATCH /api/vacancies/:id` | Изменить `user_status` |
| `GET /api/sources` | Список источников |
| `POST /api/sources` | Создать источник; необходим подходящий `test_token` |
| `PATCH /api/sources/:id` | Обновить источник или расписание; необходим `test_token` для нового YAML |
| `POST /api/sources/:id/run` | Ручной запуск; при занятом источнике — `409 Conflict` |
| `POST /api/sources/test-config` | Dry run без записи YAML и вакансий; возвращает превью и `test_token` |
| `GET /api/sources/:id/export` | Экспорт YAML |
| `POST /api/sources/import` | Импорт YAML с обязательным последующим dry run |
| `GET /api/runs/latest` | Журнал запусков |

Dry run успешен, когда YAML валиден, страница загрузилась и найдена хотя бы одна карточка с непустыми `title` и `link`. Он выполняет не более одной итерации пагинации и показывает 3–5 карточек либо понятные ошибки селекторов.

Текущий JSON-контракт: `POST /api/sources/test-config` принимает `yaml` и
возвращает `test_token`, `expires_at`, `preview`. `POST /api/sources` принимает
`slug`, необязательные `name`/`is_active`, тот же `yaml` и `test_token`.
`PATCH /api/sources/:id` требует token только когда передаётся новый `yaml`.
Token одноразовый, живёт 15 минут и связан с точными байтами YAML и `base_url`.

## Экраны

1. **Лента вакансий:** поиск, фильтры по источнику и обоим статусам, карточки, отметки «просмотрено» и «скрыто», история изменений.
2. **Сводка запусков:** карточки вида `[Ozon | +4 новых | 0 изм. | сегодня 12:00]`; выбор запуска через `run_id` показывает весь состав запуска.
3. **Конструктор источника:** YAML, расписание, dry run с лоадером и превью, сохранение после проверки, импорт и экспорт.
