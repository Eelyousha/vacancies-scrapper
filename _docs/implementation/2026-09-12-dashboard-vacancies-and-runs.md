# Локальный dashboard вакансий и запусков

**Дата:** 2026-09-12
**Статус:** выполнено
**Этап ТЗ:** [этап 4](../05-implementation-plan.md)

## Проблема и цель

Backend API уже предоставляет вакансии, источники и запуски, но пользователь
вынужден обращаться к JSON-маршрутам напрямую. Нужна первая локальная HTML-точка
входа без Node.js, CDN и клиентского фреймворка.

Цель — отобразить на `GET /` dashboard с лентой вакансий и сводкой последних
запусков, используя уже существующее хранилище и локальные статические ресурсы.

## Границы

Входит:

* серверный HTML-шаблон dashboard и локальный CSS;
* лента вакансий с отображением источника, статусов, зарплаты и ссылки;
* query-параметры `search`, `source_id`, `listing_status` и `user_status`,
  передаваемые в существующую выборку;
* сводка последних запусков с их счётчиками и состоянием;
* тесты HTTP-рендеринга, фильтра и отсутствия CDN-ресурсов.

Не входит:

* изменение пользовательского статуса вакансии из HTML, HTMX-фрагменты и
  просмотр истории;
* экран конструктора источника, dry run, import/export;
* изменение JSON API, схемы БД или логики сборщика;
* расписания.

## План и решение

Dashboard зарегистрирован отдельным `GET /` рядом с JSON API. Данные читаются
напрямую из `storage.Store`, поэтому HTML не вызывает HTTP API самого сервера.
Шаблон и CSS встраиваются в бинарник через `embed.FS`, поэтому рабочий запуск
не зависит от файлов рядом с исполняемым файлом и внешней сети.

Запрос фильтров нормализуется теми же правилами, что и API вакансий; список
источников строится из сохранённых sources. Корректный dashboard отдаёт
`text/html`, stylesheet — `text/css`.

## Проверка и результат

До реализации должны быть добавлены тесты:

1. `GET /` отдаёт HTML с названиями вакансии и источника, последним запуском и
   ссылкой на локальный stylesheet;
2. фильтр dashboard ограничивает видимые вакансии и сохраняет выбранное
   значение в форме;
3. `/static/app.css` доступен, а HTML и CSS не содержат CDN URL.

Результат:

1. `GET /` показывает вакансии, источник, зарплату, локальный stylesheet и
   сводку последнего запуска; пройдено.
2. `user_status=viewed` ограничивает ленту и сохраняет выбранный option в
   форме; пройдено.
3. `/static/app.css` доступен, а HTML и CSS не содержат CDN URL; пройдено.

Выполнены успешно: `go test ./...`, `go vet ./...`, `go build ./...` и
`git diff --check`.
