# Кнопки запуска источников на dashboard

**Дата:** 2026-09-12
**Статус:** выполнено
**Этап ТЗ:** [этап 4](../05-implementation-plan.md)

## Проблема и цель

Ручной запуск сохранённого источника доступен только на странице `/sources`,
хотя dashboard — естественная основная точка работы с вакансиями и запусками.

Цель — дать пользователю заметную кнопку запуска конкретного сохранённого
источника на главной странице без обхода API или перехода в конструктор.

## Границы

Входит: список источников на dashboard, форма `POST /sources/{id}/run` для
каждого доступного источника, отображение состояния и disabled-кнопка для
`running`; тест HTML и минимальные стили.

Не входит: поле поисковой фразы на dashboard, редактирование источника,
отмена run, фоновый запуск и обход серверной эксклюзивной блокировки.

## План и решение

Тест зафиксировал форму с ID источника, POST-метод, видимую кнопку idle source
и недоступность кнопки у `running`. Dashboard использует уже загруженные
`Sources`, поэтому дополнительных запросов или нового маршрута не требуется.
Маршрут переиспользует существующий lifecycle и redirect на отфильтрованную
ленту после успеха.

## Проверка и результат

Пройден HTTP template test для idle и running источников. Выполнены:
