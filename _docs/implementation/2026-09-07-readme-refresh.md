## Проблема и цель

Корневой README описывал ранний CLI-only этап и отрицал наличие БД/API, хотя
backend MVP уже завершён. Документационная точка входа не отражала текущий
порядок работы.

Цель — дать новому пользователю корректный запуск локального сервера, сценарий
dry run и навигацию по актуальной документации.

## Границы

Входит обновление `README.md` и `_docs/README.md`. Не входят изменения
поведения приложения и ТЗ.

## План и решение

README теперь разделяет server-first сохранение источников через dry run/API и
диагностический CLI без записи данных. `_docs/README.md` указывает состояние
backend MVP, следующие этапы и нужные разделы ТЗ.

## Проверка и результат

Проверены относительные ссылки, Markdown-разметка и `git diff --check`.
Тесты к документационному изменению неприменимы.
