# Сверка документации с реализованным MVP

**Дата:** 2026-09-12
**Статус:** выполнено
**Этап ТЗ:** [этапы 0–5](../05-implementation-plan.md)

## Проблема и цель

Часть раннего ТЗ описывает планируемые технологии и автоматизацию как уже
имеющуюся функциональность. Это противоречит README, roadmap и фактическому
локальному MVP.

Цель — синхронизировать точки входа документации с текущей реализацией и
явно отделить доступные ручные сценарии от будущих cron/interval и cursor.

## Границы

Входит: README, overview, модель данных, конфигурация сбора, roadmap, backlog
и журнал реализации. Не входит: изменение кода, схемы БД или сроков roadmap.

## Проверка и результат

Сверены README, overview, модель данных, контракт YAML и roadmap. Убраны
устаревшие утверждения о Fiber/HTMX, готовом cron-исполнителе, глобальных
лимитах браузеров и будущем `partial` для detail page. README дополнен
политикой head/reconciliation; roadmap отражает независимый timeout,
восстановление run, дедупликацию и кнопки dashboard.

Проверены внутренние Markdown-ссылки и `git diff --check`; Go-код в этом
инкременте не изменялся.

## Сверка с ТЗ и следующий шаг

Документация согласована с реализованным MVP и оставшимся roadmap. Связанная
карточка [№ 28](../backlog.md) выполнена. Следующая разработка — интерактивная
лента этапа 4.
