# Расширение README по возможностям проекта

**Дата:** 2026-09-12
**Статус:** выполнено
**Этап ТЗ:** [обзор и этапы 0–4](../01-overview.md)

## Проблема и цель

README описывает первоначальный backend API, но не отражает локальный dashboard,
конструктор источников, ручной запуск, поиск и актуальные ограничения.

Цель — дать новому пользователю точную точку входа: возможности, зависимости,
запуск, browser-сценарий, CLI и границы текущей версии.

## Границы

Входит: обновление README, ссылки на ТЗ и пример YAML. Не входит: код,
контракт API, новые сценарии или изменение roadmap.

## План и решение

README будет строиться от пользовательского сценария и содержать только
проверенные возможности. Для документационного инкремента тесты неприменимы;
проверяются ссылки, Markdown и `git diff --check`.

## Проверка и результат

Результат: README дополнен возможностями, локальным browser-сценарием,
YAML-поиском, CLI, API-документацией и честным списком ограничений. Ссылки,
Markdown и `git diff --check` проверены.

## Сверка с ТЗ и следующий шаг

Документация отражает текущую реализацию этапов 0–2 и частичный этап 4. Далее
— интерактивная лента вакансий.
