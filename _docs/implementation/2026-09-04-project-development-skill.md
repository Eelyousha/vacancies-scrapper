# Проектный skill разработки

**Дата:** 2026-09-04  
**Статус:** выполнено  
**Этап ТЗ:** применяется ко всем этапам

## Проблема и цель

`AGENTS.md` задаёт обязательные правила, но для задач разработки агенту также
нужна короткая процедура, которая быстро ведёт к нужным разделам документации,
шаблону инкремента и backlog.

Цель — добавить переносимый вместе с репозиторием skill без дублирования всех
локальных инструкций.

## Границы

Входит:

* skill в `.codex/skills/` с маршрутизацией по документации и backlog;
* ссылка на skill из `AGENTS.md`;
* карточка backlog для идеи декларативной валидации YAML-конфигурации.

Не входит:

* изменение поведения `internal/config`;
* автоматизация создания записей, миграций или тестов скриптами.

## План и решение

Skill будет компактным: обязательные правила остаются в `AGENTS.md`, а skill
только указывает, какие проектные артефакты прочитать в зависимости от типа
задачи. Это исключает расхождение двух полных копий одного процесса.

## Проверка и результат

Тесты неприменимы, поскольку меняются только инструкции. Проверены frontmatter
skill, относительные ссылки на `AGENTS.md`, backlog, шаблон и разделы ТЗ.
`AGENTS.md` назван источником обязательных правил, поэтому skill не дублирует
и не может расходиться с полной процедурой.

## Сверка с ТЗ и следующий шаг

Изменение не влияет на функциональные требования ТЗ. Ближайшая реализация по
backlog — сохранение результатов скрапера: перед кодом необходимо создать
отдельную запись инкремента и перевести её статус в `в работе`.
