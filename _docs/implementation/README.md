# Журнал реализации

Здесь фиксируются завершённые инкременты проекта. Записи дополняют общий
[порядок реализации](../05-implementation-plan.md): roadmap отвечает на вопрос
«что будет сделано», а этот журнал — «что именно и почему уже сделано».

Каждый инкремент создаётся отдельным файлом с именем
`YYYY-MM-DD-краткое-название.md`. После завершения запись не переписывается для
следующих задач: уточнения оформляются новой записью со ссылкой на прежнюю.
Это сохраняет понятную историю решений.

Для новой записи используйте
[шаблон](../templates/implementation-record.md). Очередь идей и статусы
находятся в [backlog](../backlog.md).

Новая запись должна содержать:

1. дату, статус и ссылку на этап ТЗ;
2. проблему, цель и явные границы — что не входит в инкремент;
3. принятое решение и его ключевые последствия;
4. перечень пользовательски значимых изменений;
5. сценарии проверки и их результат;
6. последующий шаг и открытые ограничения.
