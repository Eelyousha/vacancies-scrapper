# Процесс разработки и backlog

**Дата:** 2026-09-01  
**Статус:** выполнено  
**Этап ТЗ:** применяется ко всем этапам

## Цель

Закрепить единый воспроизводимый процесс для будущих инкрементов и сделать
идеи проекта видимыми до начала работы над ними.

## План

1. Добавить корневой `AGENTS.md` с обязательной последовательностью:
   план в документации, тесты, реализация, сверка с ТЗ.
2. Добавить Markdown-шаблон для записей журнала реализации.
3. Добавить backlog с короткими карточками идей и явными статусами.
4. Связать эти документы с индексом основной документации.

## Проверка и результат

Автоматические тесты неприменимы: изменяются только правила и Markdown-файлы.
Выполнена ручная проверка: корневой `AGENTS.md` содержит обязательный процесс,
шаблон доступен из индекса документации, а backlog содержит статусы и ссылки на
два уже выполненных инкремента. Markdown-разметка дополнительно проверена
`git diff --check`.

## Сверка с ТЗ и следующий шаг

Изменение не меняет функциональные требования ТЗ, но закрепляет способ их
безопасной поэтапной реализации. Следующая задача backlog — сохранение
результатов скрапера; перед ней нужно перевести её в статус `в работе` и
создать запись по новому шаблону.
