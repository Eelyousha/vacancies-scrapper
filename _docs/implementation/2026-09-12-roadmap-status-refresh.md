# Актуализация статусов roadmap

**Дата:** 2026-09-12
**Статус:** выполнено
**Этап ТЗ:** [порядок реализации](../05-implementation-plan.md)

## Проблема и цель

Раздел текущего статуса в roadmap не обновлялся с 2026-09-04 и сообщает, что
dry run, API и UI ещё не реализованы. Это противоречит журналу завершённых
инкрементов и вводит в заблуждение при выборе следующей задачи.

Цель — привести статусы и остаток работ в `_docs/05-implementation-plan.md` в
соответствие с проверенными инкрементами, без изменения кода и границ ТЗ.

## Границы

Входит:

* актуальная дата, статусы этапов 0–5 и их фактический результат;
* явный список незакрытых частей этапов 2, 4 и 5;
* обновлённая следующая задача.

Не входит:

* изменение реализации, API, модели данных или приоритета backlog;
* объявление частичного этапа завершённым;
* переписывание завершённых записей реализации.

## План и решение

Статусы выводятся только из журнала реализации и проверок: этапы 0, 1 и 3
завершены; этапы 2 и 4 продолжаются из-за точечно перечисленных функций;
этап 5 не начат. Для документационного инкремента unit-тесты неприменимы;
проверяются ссылки, Markdown и отсутствие whitespace-ошибок в diff.

## Проверка и результат

Результат: строки этапов сверены с журналом и backlog. Этап 0 отмечен
выполненным; этапы 1, 2 и 4 остаются в работе с конкретным остатком; этап 3
выполнен; этап 5 не начат. Ссылки и Markdown проверены; `git diff --check`
пройден.

## Сверка с ТЗ и следующий шаг

Изменение сохраняет текущие цели и критерии ТЗ, уточняя только прогресс. Далее
— интерактивная лента вакансий: смена пользовательского статуса и выбор
состава запуска.
